# Agentic Manipulation

用一句中文指令，让仿真机械臂找到桌上的彩色方块，把它抓起或放入指定容器。

这是一个 **Linux 桌面上的机器人仿真项目**，无需真实机械臂。当前支持红、绿、蓝三种方块，黄、紫两种容器。模型通过远程 API 看图理解任务，机器人根据 RGB-D 相机和 GraspNet 计算抓取方式。每次输入一条任务，完成后场景保持原样，可以继续输入。

## 从哪里开始

- **第一次接触项目：** 阅读 [新手使用指南](docs/getting-started.md)，里面包含前置知识、准备检查、配置、操作示例和常见问题。
- **这台开发电脑已配好环境：** 在项目根目录运行下面的命令。无需重新安装。
- **换一台电脑：** 先按 [环境准备](docs/setup.md) 和 [GraspNet 准备](docs/graspnet-setup.md) 手动准备两个环境、源码与权重，再回到新手指南。尚未在全新机器从零复现，不能保证直接安装即成功。

```bash
/home/fatbro/software/miniforge3/envs/am-sim/bin/python -m agentic_manipulation.demo
```

如果你已经在 `am-sim` 环境，等价命令是：

```bash
python -m agentic_manipulation.demo
```

看到终端提示 `Task >` 后，每次输入一行并按回车：

```text
把红色方块放进黄色容器
把绿色方块放进紫色容器
抓起蓝色方块
把蓝色方块放进黄色容器
quit
```

等待上一条执行结束后再输入下一条。`reset` 重置场景；`quit` 退出。只抓起时机械臂会保持夹持，下一条可以要求把同一方块放入容器。

## 你会看到什么

原有机械臂执行窗口、彩色图／深度／点云调试窗口保持不变；额外弹出三栏窗口，依次显示目标与容器定位框、灰度深度、GraspNet 选中抓取的投影及分数和开口宽度。三栏窗口在执行期间保留规划观测帧，验证时换成新观测；可单独关闭，不中断任务。每轮选中抓取的三栏截图保存为 `grasp-debug.png`。

终端实时输出观察、场景定位、规划、识别轮次、抓取相机坐标与末端世界坐标、抓取／放置、验证、重试原因及任务结果。日志来自实际执行事件，不输出逐帧信息。等待模型回复时会保留最近画面。结果自动写入 `outputs/demo/` 下的新会话目录。

发生碰撞、超时、连续连接失败或无法可靠完成任务时，系统会停止；输入 `reset` 后才能开始新任务。远程模型可能误判，项目并不保证任意场景都能完成。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `agentic_manipulation/` | 仿真、五个模块、闭环控制与 Demo 源码 |
| `tests/` | 12 个必要离线检查用例，以及真实异常验收脚本 |
| `docs/` | 使用、环境、设计及开发记录 |
| `docs/validation/` | 精选验收报告与历史演示，随项目保留 |
| `patches/` | 上游 GraspNet 样例的最小修复补丁 |
| `.env.example` | 模型配置模板，无真实密钥 |
| `third_party/`、`weights/` | 本地依赖源码和模型权重，用户手动准备，不纳入 Git |
| `outputs/` | 运行时自动生成的日志、图像与视频，可在程序退出后删除 |
