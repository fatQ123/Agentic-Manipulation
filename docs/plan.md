# 三版开发与发布计划

依据用户确认的规划实施；后补的 `Agent.md` 约束优先。仅做仿真：Panda 单臂、固定相机、桌面方块与碗。

## v1.0.0：视觉抓取

内部顺序：环境与 Vulkan → ManiSkill `PickCube-v1` → RGB-D → 点云与可视化 → GraspNet 独立推理 → 抓取坐标系适配 → 关键点抓取执行。

V1 已完成；本轮模块整理只做最终单任务命令兼容检查，不再跑十场景。不得把几何合成测试称作真实仿真成功，也不得用硬编码抓取替代 GraspNet 验收。

GraspNet 使用独立 `am-grasp` 环境，与 `am-sim` 通过子进程及 NumPy 文件交换数据。环境和依赖下载全部由用户手动完成。先运行官方推理样例，再固定依赖组合，不提前声称兼容。

米为统一长度单位；`T_A_B` 表示 B→A。点云使用 OpenCV 相机坐标（右、下、前）。显式处理相机→世界→基座，以及 GraspNet 抓取坐标系→Panda 末端的固定变换。

执行依次为预抓取、接近、闭爪、抬升和保持。复用 ManiSkill IK 和末端控制器，并处理到达误差、超时、候选可达性和碰撞。

发布门槛：固定种子 0–9 的十个场景至少成功 8 次；方块底部离桌至少 5 cm，夹持保持 1 秒。真实状态只用于评测／调试，不用作视觉目标定位输入。

## v2.0.0：语言驱动搬运

加入不同颜色方块、可容纳方块的碗及位置变化。接一个可配置地址、模型名和密钥的 OpenAI 兼容图文服务，正式验收固定服务与模型。

支持 `pick` 与 `pick_place`，VLM 输出物体、目标容器及图像目标框。通过当前深度定位三维区域，复用 V1 执行抓取、转移、放置和撤离。错误响应、歧义、缺失目标和超时不得进入执行。

发布门槛：固定十组指令和场景至少成功 8 次；正确方块进入正确碗内，脱离夹爪并稳定 1 秒。此版本不自动重试物理任务。

## v3.0.0：闭环智能体

重新观察后由 VLM 返回成功／失败／无法判断及理由。失败时按最新状态重新抓取或重新放置，不复用过期目标框。每任务最多 3 轮执行，总时限为 180 秒；不可恢复状态明确终止。

发布门槛：复用 V2 场景，3 轮内至少成功 9/10，且不低于 V2；验证首次抓取失败、放置失败和无法恢复情况。用仿真真实状态独立判分，统计 VLM 误判，不以模型声称成功代替真实结果。

## V3 完善：五模块与持续交互（2026-10-13 更新）

以用户最新上传计划为准，V1 8/10、V2 10/10、旧 V3 10/10 仅作历史基线。保留现有算法、标定、红绿蓝方块、黄紫容器和远程 VLM；每次只输入一个目标任务。

实施顺序：VLM Backend → Task Planner → Placement Planner → Grasp Selector → Resource Manager → V3 接入 → 持续 Demo → 调试 UI → 显存标定 → 清理重复实现 → 集中验收 → 文档收尾（正式录像按用户后续要求暂缓）。现有相同部署的显存实测保留，不重新测量来阻塞功能推进。

功能阶段只检查接口、输入输出和必要错误边界，不运行 V1/V2/V3 成功率批次。旧调用方迁移后删除重复实现，不建立长期兼容层。状态分开记录为 `IMPLEMENTED`、`INTEGRATED`、`VALIDATED`。

最终验收一次集中完成：V3 固定十场景，目标 10/10；抓空恢复、未释放重放、目标丢失、只抓取、网络与子进程故障、窗口关闭和中断；同场景红→黄、绿→紫、蓝→黄三次搬运；抓起红色后下一条直接放入黄色容器；V1/V2 各一个代表任务。只在失败暴露具体问题时调查，不通过反复整批或拼接成功样本制造通过结果。

持续演示保存场景与夹持状态；Task Planner 检查已夹持目标，直接放置不再调用 GraspNet。首次验证不确定时有界重新观察，恢复后仍不确定则 STOPPED。资源故障、碰撞、超时和最终失败同样停止，只接受 reset/quit；重置不覆盖历史记录。真实物体位姿只参与评测，不决定恢复。

接口、状态、默认命令和资源依据见 [五模块与持续演示](modules-demo.md)。已统一更新 README 与五类记录。用户随后要求停止录像、优先完成 Demo，正式演示录像暂缓。

## 发布纪律

- 本地开发分支 `work` 保留小步提交；每版验收后才生成一次面向 GitHub 的阶段提交。
- 首次发布建立只含完整 V1 快照的 `main`；后续每版在其上增加一个完整阶段提交，保留本地开发历史，不强推改写已发布历史。
- 仅发布 v1.0.0、v2.0.0、v3.0.0 三个 Tag／Release，不推送本地开发分支。
- 每版附环境记录、运行说明、完整验收结果、演示及限制；未验收不发布。
- 权重、临时数据和密钥不进 Git。保留模型来源与上游版本；依据新增约束，不编写兼容层或哈希校验代码／测试。
- 环境具体版本在真实运行通过后记录；不把候选安装说明当作锁定环境。

不纳入三版：实机、本地 VLM、模型训练、任意物体、复杂障碍物规划、网页界面、多智能体框架。
