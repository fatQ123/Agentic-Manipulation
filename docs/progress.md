## 启动

项目根目录执行：

```bash
/home/fatbro/software/miniforge3/envs/am-sim/bin/python -m agentic_manipulation.demo
```

逐条输入“把红色方块放进黄色容器”“抓起蓝色方块”“把蓝色方块放进黄色容器”。`reset` 重置当前种子，`quit` 退出；失败进入 STOPPED 后仅接受重置或退出。窗口与产物说明见 [演示说明](modules-demo.md)。
