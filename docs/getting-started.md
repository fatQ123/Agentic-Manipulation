# 新手使用指南

目标是先成功完成一次“把红色方块放进黄色容器”，再了解内部原理。运行 Demo 不需要先学会机器人算法，也不需要真实机械臂。

## 1. 需要先了解哪些知识

| 知识 | 学到什么程度即可 | 在哪里用到 |
| --- | --- | --- |
| 终端和目录 | 会打开终端、用 `cd` 进入文件夹；知道相对路径从当前目录开始 | 从项目根目录启动 |
| Python 环境 | 知道不同环境有不同的 Python 和依赖；会确认自己使用哪个解释器 | am-sim 运行仿真，am-grasp 运行抓取模型 |
| API 配置 | 知道服务地址、模型名、密钥的区别；密钥不要公开 | 配置远程看图模型，调用会产生服务商用量 |
| 显卡与驱动 | 会读 `nvidia-smi` 的显存信息；知道显卡驱动与 CUDA 编译工具不是一回事 | 仿真渲染、GraspNet 推理 |

想修改算法时，再学习以下概念，不必在首次运行前全部掌握：

- **RGB-D：** RGB 是彩色图，D 是每个像素对应的距离。彩色图用于找目标，深度用于计算三维位置。
- **点云和坐标系：** 把深度像素变成三维点。相机坐标、世界坐标和机械臂坐标必须正确转换；本项目距离单位是米。
- **抓取姿态与 IK：** 抓取姿态是夹爪的位置和朝向；IK（逆运动学）用来检查机械臂能否到达指定姿态。
- **VLM 与 GraspNet：** VLM 是能看图的语言模型，负责理解“抓什么、放哪里”和判断结果；GraspNet 根据点云提出抓取候选。
- **闭环：** 动作后重新看图，再决定完成、恢复或停止。这里最多三轮、每条任务最多 180 秒。

建议按“运行一次 → 阅读 [模块说明](modules-demo.md) → 看 `task_planner.py` → 看几何与抓取代码”的顺序学习。无需为这个 Demo 先学习 ROS 或训练模型。

## 2. 启动前检查

当前实测平台是 Linux Mint 22.3、RTX 3060 Laptop 6 GB、带桌面的图形环境。其他系统或显卡尚未完整验证。需要网络能访问所配置的远程模型。

打开项目文件夹中的终端。目录里应能看到 `README.md` 和 `agentic_manipulation`。后续命令都在这里执行。

确认有以下内容：

| 内容 | 如何确认 |
| --- | --- |
| am-sim 环境 | 能运行 ManiSkill、SAPIEN、NumPy、SciPy、Pillow、Matplotlib 和 imageio |
| am-grasp 环境 | 已安装 GraspNet 所需 CUDA 扩展，且真实推理通过 |
| 依赖源码 | 存在 `third_party/graspnet-baseline/` |
| 权重 | 存在 `weights/checkpoint-rs.tar`，不要解压 |
| 模型配置 | 根目录存在填写完整的 `.env`，见下一节 |
| 显存 | 当前单 GPU 部署在推理前要求至少 1398 MiB 空闲；这是仿真已启动后的余量，不是整套系统最低显存 |

**现有开发电脑已完成环境与权重准备，不要重复安装。** 新电脑按 [环境准备](setup.md) → [GraspNet 准备](graspnet-setup.md) 操作。所有安装由使用者手动执行，包清单是已运行环境记录，不是通用一键安装文件。

## 3. 配置远程模型

首次使用时，将项目根目录 `.env.example` 复制一份，命名为 `.env`，用文本编辑器填写三个值。已有 `.env` 时直接检查，不要覆盖它。

```text
VLM_BASE_URL=https://服务商提供的地址/v1
VLM_MODEL=服务商提供的视觉模型名称
VLM_API_KEY=你自己的密钥
```

以上是格式示意，不能原样连接。地址使用服务商给出的 API 基础地址，程序会追加 `/chat/completions`。服务必须支持看图及 JSON 输出模式；普通文本模型不够。程序会发送当前仿真彩色图和指令，调用可能产生费用。不要把 `.env` 或密钥上传到仓库或截图公开。

如果终端已经设置了同名环境变量，它们会覆盖 `.env`。更改文件后仍使用旧配置时，优先检查这一点。

可先测试文本连接（会真实调用服务）：

```bash
python -m agentic_manipulation.check_api
```

这里和下文的 `python` 都指 am-sim 的解释器。文本通过不代表图像能力也通过；需要时按 [API 检测说明](api-check.md) 检查一张图片。不要因为一次失败就反复启动完整演示。

## 4. 启动 Demo

在已经准备好的 am-sim 环境执行：

```bash
python -m agentic_manipulation.demo
```

当前开发电脑也可以直接使用完整路径，无需切换终端环境：

```bash
/home/fatbro/software/miniforge3/envs/am-sim/bin/python -m agentic_manipulation.demo
```

这个绝对路径只适用于当前电脑。其他电脑请用自己的解释器路径。

默认会寻找同级环境中的 `am-grasp/bin/python`。如果两个环境不在同一环境目录，用下面的参数指定实际位置，先将示例路径替换成自己的路径：

```bash
python -m agentic_manipulation.demo --grasp-python /你的环境路径/am-grasp/bin/python --checkpoint weights/checkpoint-rs.tar
```

初始化后会打开两个窗口，并在终端显示 `Ready` 和 `Task >`。指令输入在**终端**，不是图形窗口。

## 5. 完成第一组任务

先输入下面第一行并按回车；等它结束、再次显示 `Task >`，再输入下一行。不要一次粘贴整组任务。

```text
把红色方块放进黄色容器
把绿色方块放进紫色容器
抓起蓝色方块
把蓝色方块放进黄色容器
```

前两条完成后，物体位置会保留。第三条只抓起并保持；第四条直接把夹持中的蓝色方块放进去。已夹持时要求抓另一个物体会被拒绝。

每条任务只说一个目标，例如“把红色方块放进黄色容器”。“整理桌面”“先抓红色再抓绿色”超出当前范围；“抓一个方块”可能因目标不明确被拒绝。

常用操作：

| 输入／操作 | 作用 |
| --- | --- |
| `reset` | 恢复当前种子的初始场景，清除停止和夹持状态，保留已有结果文件 |
| `quit` | 退出并释放资源 |
| Ctrl-C 或关闭任一窗口 | 中断并退出；同步网络请求时关闭窗口可能延后处理 |

## 6. 看懂窗口和结果

SAPIEN 窗口是机械臂的实际仿真执行画面。调试窗口显示 RGB、深度、三维点云、选中的抓取方向及阶段。点云表示规划时的观测，不是始终实时重建；动作开始后会清除旧目标框。

“等待模型规划／验证”表示正在请求远程服务，画面暂时保留是预期行为。`HOLDING` 表示仍夹着物体；`STOPPED` 表示本轮已停止，只接受 `reset` 或退出。不要把模型等待误当成需要再输入一次任务。

终端结果中：`success` 是仿真真实状态的独立判分，`agent_status` 是模型判断，`state` 是控制器状态。三者并非同一个概念，可能不一致。

每次启动自动创建 `outputs/demo/session-时间/`：

- `session.json`：这一会话执行了哪些任务及其结果。
- `task-001/result.json` 等：每条任务的状态、判断、耗时与资源记录。
- 各轮目录：观测、目标框、点云、抓取候选和执行后验证。
- 视频和调试图片：用于回看；相机视频按仿真帧编码，不包含网络等待的实际时长。

输出属于可删除的运行产物。先退出程序，再删除不需要的会话目录即可；需要排查失败时保留对应 `result.json` 和相关图像。不要删除 `weights/` 或 `third_party/` 来清理输出。

## 7. 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 找不到 `agentic_manipulation` | 是否在含 README 的项目根目录；是否用了正确 Python |
| 缺少 Python 包或 CUDA 扩展 | 对照两个环境的准备说明；不要把 am-grasp 依赖混装到 am-sim |
| 提示缺少 `VLM_*` | `.env` 是否在根目录、三个值是否完整，是否有环境变量覆盖 |
| HTTP、TLS、连接或超时错误 | 先用 API 检测确认服务；V3 只额外重试一次连接错误，之后会停止 |
| 显存不足或监测不可用 | 检查 `nvidia-smi`；手动关闭不需要的 GPU 程序，不要降低阈值强行启动 |
| 窗口打不开 | 是否在有桌面的 Linux 会话、GPU/Vulkan 驱动是否可用 |
| 任务被拒绝但还能输入 | 用明确颜色描述一个方块和一个容器，避免多步或模糊指令 |
| 动作后进入 STOPPED | 查看失败原因，输入 `reset` 后再尝试；不要在未知夹持状态下强行继续 |
| 输出目录已存在 | 换一个新 `--output` 路径，或省略该参数使用自动时间目录 |

当前效果限定为这些颜色方块、容器和单视角桌面场景。固定十场景通过不代表任意物体、遮挡、网络或实机都可靠。
