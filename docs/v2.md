# V2：自然语言搬运

固定十组指令与场景 **10/10 通过**，达到 8/10 本地验收门槛，尚未发布。见 [完整报告](validation/v2-results.json) 与 [演示录像](validation/v2-demo.mp4)。使用用户现有 am-sim、am-grasp 与权重，不安装额外依赖。

## 配置

项目根目录 `.env`（已被 Git 忽略）填写 `VLM_BASE_URL`、`VLM_MODEL`、`VLM_API_KEY`；进程环境变量优先。地址为 OpenAI 兼容 API 的基础地址（例如以 `/v1` 结尾），程序追加 `/chat/completions`。远程连接要求 HTTPS，不自动跟随重定向，不记录认证头或错误响应正文。仅发送当前 RGB 图片和任务指令，不上传深度、密钥文件或项目文件。

服务须支持图文 chat completions 和 `response_format={"type":"json_object"}`，并直接返回 JSON 文本。响应截断、拒绝、未知动作、非法目标框、缺少目标、连接失败均停止本次任务。没有模型调用重试或物理任务重试。

## 运行

从项目根目录运行，输出目录必须不存在：

```bash
# 单次语言搬运；也支持“抓起蓝色方块”这种只抓取指令。
/home/fatbro/software/miniforge3/envs/am-sim/bin/python -m agentic_manipulation.pick --instruction '把红色方块放进黄色碗里' --seed 0 --output outputs/v2-example --grasp-python /home/fatbro/software/miniforge3/envs/am-grasp/bin/python --checkpoint weights/checkpoint-rs.tar

# 固定十组指令和场景，失败保留在分母中。
/home/fatbro/software/miniforge3/envs/am-sim/bin/python -m agentic_manipulation.evaluate --v2 --output outputs/v2-evaluation --grasp-python /home/fatbro/software/miniforge3/envs/am-grasp/bin/python --checkpoint weights/checkpoint-rs.tar

# 已保存画面的语言解析，不启动机械臂。
/home/fatbro/software/miniforge3/envs/am-sim/bin/python -m agentic_manipulation.vlm outputs/v2-example/capture/rgb.png --instruction '把红色方块放进黄色碗里'
```

省略 `--instruction` 仍运行 V1。V2 有红、绿、蓝方块，以及黄、紫两只方形开口碗，位置与颜色排列随种子变化。固定相机配合机械臂收回的观察姿态，避免初始夹爪遮住方块。碗是带底部和四面碰撞墙的静态容器，内宽 14 cm、底面高 1 cm、上沿高 5 cm。

VLM 返回 `status`、`action`、`object`、`destination`；物体字段含 `color` 和归一化至 0–1000 的 `bbox=[x1,y1,x2,y2]`。`pick` 的 destination 必须为空，`pick_place` 必须给出容器。用目标框的重叠选择完整颜色连通域，结合当前深度重建点云，再送入 GraspNet。容器放置位置同样从图像和深度计算，不读取真实物体位置作为规划输入。抓取后在高处将夹爪调整为竖直放置方向，通过夹持坐标系中的观测偏移保持目标对齐；整个关键点序列在执行前检查 IK。

输出保留 `capture/`、`plan.json`、`cloud/`、`grasps/`、`inference.log`、`pick.mp4`、`result.json`。失败发生在哪一步，就保留此前产物；以 `result.json` 的 success 为准。验收按预先固定的指令核对目标颜色，并用仿真真实状态检查方块整体在正确碗内、脱离夹爪、低线速度和角速度稳定一秒。

限制：仅支持此固定色彩与容器几何；颜色分割不是通用实例分割，单视角遮挡可能导致拒绝或失败。关键点路径沿用接触监测，不能代替任意障碍物运动规划。V3 的视觉反馈重试不在本版本中实现。
